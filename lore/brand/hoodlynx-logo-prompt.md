# HoodLynx Logo — Flat Master Prompt

Reusable prompt to generate a clean flat logo so you don’t re-roll character art every time.

## Core symbol rules

- Hooded lynx head / face mark
- **Chain around the neck**, broken open at the bottom
- **Fragment / chain piece connected on the head** (forehead)
- Flat logo, not a cinematic scene
- Neon lime green on black (or single-color green mark)

## Primary prompt (paste this)

```text
Flat vector logo mark for HoodLynx, centered on a pure black background.
Simple iconic emblem only — no scene, no background environment, no poster layout.

Subject: a stylized hooded lynx head / face symbol, front-facing, bold geometric silhouette.
On the forehead / top of the head: a connected chain-link Fragment piece integrated into the design (small chain segment or single link resting on/through the forehead).
Around the neck: a chain collar that wraps the neck area and is clearly broken open at the bottom (gap / severed links at the bottom center).

Style: flat logo, clean vector, sharp edges, minimal detail, high contrast, premium emblem design.
Color: neon lime green (#39FF14-like) linework and fills on solid black. Single-color mark. No gradients if possible, or very subtle green glow only.
Composition: centered, lots of clear padding, looks perfect as a profile picture, book stamp, jacket patch, and app icon.
No text, or optional tiny arched text "HOODLYNX" under the mark in matching green sans-serif — prefer NO text in the first version so the icon stands alone.

Avoid: photoreal fur, cinematic lighting, full body character, weapons, city background, HUD clutter, crystals, purple, crowns, owls, busy details, noise, blur, watermark, 3D clay render, comic shading.
```

## Stricter logo version (if it keeps making “art” instead of a mark)

```text
Create a flat 2D brand logo icon, not an illustration.
Hooded lynx head emblem, front view, thick clean strokes.
Forehead has one chain-link fragment attached.
Neck has a chain that is broken at the bottom.
Neon green on black.
Vector logo, centered, simple, scalable, no background scene, no extra objects.
```

## Negative prompt

```text
photorealistic, cinematic scene, full body, detailed fur, city, HUD, text paragraphs, crystal, purple, crown, owl, noisy, blurry, 3D render, complex background
```

## Export tips

- Ask for: transparent background PNG if supported, or black background master
- Also ask for: “single-color green only version” for stamps / embroidery clarity
- Keep one master file and reuse it on books, jackets, terminal UI, and post corners
