# Canon Rules (Anti-Hallucination)

When writing HoodLynx story, posts, site copy, or puzzles:

## Allowed

- Restate what is already written in this `lore/` folder
- Rephrase for tone (terminal / transmission / archive voice)
- Connect established dots that are already stated
- Flag gaps instead of filling them

## Forbidden

- Invent new factions, orders, locations, or mechanics
- Invent causes of the Severing beyond what is written
- Treat unused brainstorm ideas as published canon
- Merge conflicting names without an explicit decision recorded here

## Source priority (highest → lowest)

1. **Published posts / live site** (once archived under `posts/`)
2. **Agreed canon files** in `world/`, `factions/`, `orders/`, `arc/`
3. **Mind map / chat dumps** in `source/`
4. Speculative notes — never use unless promoted into canon

## When unsure

Write: `UNCONFIRMED` or add a line to `OPEN_QUESTIONS.md`.
Do not guess.
