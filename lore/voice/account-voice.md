# Account Voice Guide

Derived only from confirmed posts. Use this for continuity.

## Core posture

- Transmission / classified network energy
- Urgency without hype-bro slang
- Scarcity via windows that open and close
- Mystery: origin unknown, purpose classified
- Invitation into **the hunt**, not a normal mint promo

## Signature lines

- **FOLLOW THE SIGNAL.**
- Often paired with: `🏹😼` (posts 001–002; post 003 drops emoji)
- Destination: `http://hoodlynx.xyz` (casing sometimes `Hoodlynx.xyz`)

## Recurring words

- signal / transmission / access / window
- hunt / hunters
- whitelist / WL / applications / submissions
- shadows / classified / network (as the ARG deepens)

## Structure pattern (early WL posts)

1. Alert headline (caps or ellipsis transmission open)
2. 1–3 short lines of mystery + stakes
3. Scarcity / time pressure
4. Link
5. **FOLLOW THE SIGNAL.** (+ optional emoji)

## Structure pattern (mission / narrative posts)

1. Ellipsis system lines (`...SIGNAL RECEIVED.` / `...ACCESS PROTOCOLS HAVE CHANGED.`)
2. FILE / mission block or short directive lines
3. Clear action (tag a friend / locate the terminal)
4. Optional scarcity (“first 100”, “you don’t have long”)
5. Optional link + FOLLOW THE SIGNAL (on graphic if not in body)

## Confirmed mission spelling

- Public mechanic uses **LYNK** (FILE-01), not “link”

## Picture-hint posts

- Body copy stays short; lore clues live in the image
- Keeper rooms = knowledge / code / decryption prep
- Hunter rooms = recovery / Fragments / Severing investigation
- Do not over-explain the puzzle in the caption

## Freshness rule

- One new beat per post
- Don’t recap prior Fragment status unless the Terminal must prove a sync
- Repeat only signature glue: FOLLOW THE SIGNAL / site / transmission tone
- If yesterday said “need Hunters,” today should move the Signal — not repeat the ask in the same words

## Live faction split (for continuity)

- **Hunters** follow Signal → find Fragments
- **Seekers** seek knowledge → decrypt Fragments

## Fragment cadence pattern (001 → 002)

1. Recovery / decrypting status
2. Decrypted + archive truth tease
3. Limited **Authorized Hunter Access** window
4. Next Fragment Signal detected / located
5. Smaller auth window before decryption begins
6. Archive expands / Follow the Signal

## What to avoid (based on what these posts do *not* do)

- Long paragraphs
- Roadmap dump in the post body
- Explaining the whole lore up front
- Softening urgency with “gm” / meme filler
- Inventing new faction names before they appear in posts
- Inventing new numbered systems (logs, sites, files) that don’t already exist
- Too many proper nouns in one caption — stick to `TERMS.md`

## Public brand lines (from site / graphics — not deep lore)

- Tagline: **FOLLOW THE SIGNAL**
- Descriptor seen on graphics: **CROSS-CHAIN VALUE HUNTERS**
- Site blurb: on-chain hunters tracking high-signal opportunities; built for Robinhood Chain; powered by the community
- Launch: Robinhood Chain
- Mint tease: Coming soon to Gravemint.io

Deep cosmology (Chain / Severing / Fragments) arrives later in Fragment posts — keep early voice lighter and signal-first.
