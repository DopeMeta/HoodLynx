## Principle: don’t spray perks — build a loop

Smart holder value is a loop, not a laundry list:

1. **Mint / hold** HoodLynx (GraveMint)  
2. **Signal Standing** rises with hold + participation  
3. **Stake** into faction pools (GraveStake)  
4. **Earn** entries / boosts / WL / loot (GraveDraw + future drops)  
5. **Trade / flex** on GraveMarket without leaving the story  
6. Story reacts (Archive, Broken Glitches, Crown Decrees)

Lore names for the loop:
- GraveMint = **Activation Gate**  
- GraveStake = **Signal Anchors** / **Path Locking**  
- GraveDraw = **Signal Lotteries** / **Fragment Raffles**  
- GraveMarket = **Exchange of the Path** / **Black Market of Marks**

## Tier benefits by what you can actually run

### A. GraveStake — strongest “smart” benefit
**Idea:** HoodLynx staking programs as *locking your Activation into the Path.*

| Pool (lore name) | Who | Reward ideas |
|------------------|-----|----------------|
| Hunter Anchor | Hunter-leaning / any holder | Future WL weight, raid entries |
| Seeker Archive Lock | Seekers / book traits | Early lore drops, puzzle keys |
| Crown Tithe | Crown-marked | “sanctioned” cosmetics / decree votes |
| Broken Contamination | Broken / skull | Chaos draw tickets, Glitch sale early pings |

**Intelligent design:**
- One **global HoodLynx stake** first (simple), then faction sub-pools
- Rewards can be: points, draw tickets, WL spots, partner allocations, $ecosystem if/when relevant — start with **access + tickets**, not fake APY promises
- Staked still count for holder roles if GraveKeeper-style gating exists

**Why it’s bullish:** holding stops being passive JPEG; it’s Path participation.

### B. GraveDraw — excitement without dumping supply
**Idea:** periodic **Signal Draws** funded by treasury / mints / partners.

Examples:
- Weekly **Fragment Raffle** for stakers only  
- **Broken Glitch Draw** (chaotic, short window — fits lore)  
- **Crown Decree Draw** (exclusive “order” prizes)  
- Milestone draws at 1k / 2k / 3k / sellout Activations  

Prizes that don’t wreck floor:
- Free mints / discounts on *next* HoodLynx wave or side drop  
- Partner WL  
- 1/1 Archive art  
- Custom trait / rename / lore mention  
- Stake boost multipliers  

**Rule:** Draws reward **stakers + active Signal followers**, not pure luck for flippers only.

### C. GraveMarket — liquidity + culture
**Idea:** Make GraveMarket the official Path exchange.

Benefits:
- Holder trading feats on Flex Wall / leaderboards (if mint tools carry over)
- “Verified Path” collection presence — safe venue narrative  
- Faction showcase listings (Broken Fridays, Crown Courts)  
- Royalty story: % routes to **Archive Fund** (lore) used for draws/stake rewards  

**Intelligent move:** announce GraveMarket as *where Activations circulate* once secondary starts — reduces scatter.

### D. GraveMint — keep using launch tools mid-mint
You’re not done minting. Use native mint surface area:
- **Mint parties / activity feed / flex wall / XP leaderboards** as Standing theater  
- Bonus XP or draw tickets for mint streaks  
- “Activation milestones” celebrated on-platform, not only on X  

Lore skin: leaderboard = **Hunter Standing board**.
